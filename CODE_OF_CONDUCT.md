# Code of conduct / 행동 강령

## English

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). It applies to issues, pull requests, discussions and every other project space.

In short: be respectful and constructive, assume good intent, and keep criticism about the work, not the person. Harassment, insults and personal attacks are not accepted.

The repository owner ([jacking75](https://github.com/jacking75)) enforces this code and may edit or remove contributions and block participants who do not follow it. To report a problem without discussing it in public, open an issue that asks for a private contact channel, without including the details.

## 한국어

이 프로젝트는 [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)을 따른다. 이슈, 풀 리퀘스트, 토론 등 프로젝트의 모든 공간에 적용된다.

요약하면, 서로 존중하고 건설적으로 대하며, 선의를 전제하고, 비판은 사람이 아니라 작업을 향하게 한다. 괴롭힘, 모욕, 인신공격은 허용하지 않는다.

저장소 소유자([jacking75](https://github.com/jacking75))가 이 강령을 집행하며, 따르지 않는 기여를 수정하거나 삭제하고 참여자를 차단할 수 있다. 공개적으로 논의하지 않고 문제를 알리려면, 세부 내용 없이 비공개 연락 수단을 요청하는 이슈를 연다.

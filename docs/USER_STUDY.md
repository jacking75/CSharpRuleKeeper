# 사용자 체험 계획

목표 집단은 C# 개인 개발자, 작은 .NET 팀 개발자, 게임 서버 개발자 등 5명이다. 모집·연락·게시와 개인정보 수집은 별도 명시적 동의 후 수행한다.

과제는 설치, 샘플 검사, 보고서에서 문제 찾기, 안전한 수정, 재검사, 자기 프로젝트 적용 순서다. 설치 성공, 첫 유효 보고서 시간, 채택률, 오탐 사유, 수정 후 테스트, 1~2주 뒤 재사용 의사와 실제 사용을 기록한다. 취향 불일치와 Analyzer 오탐은 분리한다.

에이전트 비교는 같은 샘플·모델·지시문으로 도구 없음/있음을 비교하고 반복 수, 시간, 남은 위반, 계약 변경, 테스트 결과를 기록한다. 5명 중 4명의 무지원 첫 보고서와 서로 다른 실제 프로젝트 3개의 사례는 제안된 완료 기준이지 달성 결과가 아니다.

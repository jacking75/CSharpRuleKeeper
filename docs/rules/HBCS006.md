# HBCS006: 메서드 물리 줄 수

## 목적
긴 메서드를 책임 분리 후보로 표시한다.
## 기본 심각도
30줄 초과 `warning`, 100줄 초과 `error`다.
## 위반 예제
31줄 메서드는 경고다.
## 통과 예제
30줄 메서드는 통과한다.
## 예외
생성 코드를 제외한다.
## 옵션
`method_lines_warning`, `method_lines_error`다.
## 경계값
첫 토큰부터 마지막 토큰까지 세며 잘못된 쌍은 두 기본값으로 복원한다.
## 자동 수정
제공하지 않는다.
## 계약 변경 위험
분리할 때 제어 흐름·예외·호출 순서를 보존해야 한다.

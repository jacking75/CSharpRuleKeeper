# HBCS007: 타입 물리 줄 수

## 목적
큰 타입을 책임 분리 후보로 표시한다.
## 기본 심각도
300줄 초과 `warning`, 500줄 초과 `error`다.
## 위반 예제
301줄 타입은 경고다.
## 통과 예제
300줄 타입은 통과한다.
## 예외
생성 코드, EF Migration 파생 타입, 설정한 이름 접미사를 제외한다.
## 옵션
`type_lines_warning`, `type_lines_error`, `type_length_excluded_suffixes`다.
## 경계값
첫 토큰부터 마지막 토큰까지 세며 잘못된 쌍은 두 기본값으로 복원한다.
## 자동 수정
제공하지 않는다.
## 계약 변경 위험
타입 분리는 공개 API와 직렬화 계약을 보존해야 한다.

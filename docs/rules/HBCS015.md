# HBCS015: 소스 파일 물리 줄 수

## 목적
한 파일에 과도한 책임이 모이는 일을 경고한다.
## 기본 심각도
500줄 초과 `warning`, 1000줄 초과 `error`다.
## 위반 예제
501줄 파일은 경고다.
## 통과 예제
500줄 파일은 통과한다.
## 예외
생성 코드를 제외한다.
## 옵션
`file_lines_warning`, `file_lines_error`다.
## 경계값
주석과 빈 줄을 포함하며 잘못된 쌍은 두 기본값으로 복원한다.
## 자동 수정
제공하지 않는다.
## 계약 변경 위험
파일 분리 시 partial, namespace, 접근성과 빌드 포함 규칙을 확인한다.

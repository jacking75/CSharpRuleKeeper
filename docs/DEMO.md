# 2분 데모 대본

1. `-Doctor`로 설치 SDK와 대상 정책을 확인한다.
2. 샘플 복사본을 `DEMONSTRATE_RULES`로 검사한다.
3. Markdown에서 HBCS001·002와 계약 주의를 찾고 JSON의 `analysisCompleted`를 확인한다.
4. public 필드와 boolean 이름을 안전하게 고치고 테스트한다.
5. 같은 명령을 재실행해 진단과 실행 상태를 함께 확인한다.

실제 실행에서 얻은 전후 코드와 보고서만 공개 자료로 사용한다. 홍보 초안의 핵심은 “대상 프로젝트를 수정하지 않는 로컬 검사”, “HBCS 0개와 분석 완료의 구분”, “공개 API·직렬화 계약 자동 변경 금지”다. 외부 게시 전 채널 규칙을 확인한다.
